# TinyVoice - Voice Recorder

Offline voice recorder. No account, no cloud, no watermark.

- Record with pause/resume (foreground mic service, survives screen-off)
- Live waveform while recording
- Recording list with durations, playback, rename, trim, share, delete
- AAC encoding, saved to Music/TinyVoice on device
- AdMob banner on the recordings list only — never during recording

Built via GitHub Actions cloud build. Signed release AAB for Play Console.
